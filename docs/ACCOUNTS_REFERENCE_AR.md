# مرجع الحسابات (إدارة جودة المستقبل)

| الدور | اسم المستخدم (افتراضي) | متغير البيئة |
|--------|-------------------------|--------------|
| **مدير النظام** (لوحة الإدارة، superuser) | `badr9090` | `PRIMARY_ADMIN_USERNAME` |
| **مسوّق مرجعي / الأوّل في القوائم** | `b1` | `PRIMARY_MARKETER_USERNAME` |

- الترتيب في قوائم المدير: المدير أولاً، ثم المسوّق المرجعي (`b1`)، ثم بقية الموظفين أبجدياً.
- لا يُنشئ Django المستخدمين تلقائياً؛ أنشئ الحسابات من لوحة الإدارة أو `createsuperuser` ثم طابق الأسماء مع المتغيرات أو عدّل `.env`.
