# بورصة وزارة العدل (SREM) — المسار الموحّد

## الهدف
استغلال **بيانات API الرسمية** فقط في المؤشرات المعروضة، دون توليد عشوائي لأسعار المتر.

## التدفق
1. **`AreaStatService.sync_area_stats()`**  
   **الأولوية:** `GetTrendingDistricts` — أحياء ضمن مؤشر الترند للمدينة (أسماء حقيقية + إجمالي صفقة/مساحة/قيمة).  
   **احتياط:** `GetAreaInfo` إذا عُطّل الترند أو فشل الطلب.

2. **`sync_realestate_index_from_area_stats()`** (`market/services/srem_pipeline.py`)  
   ينسخ آخر لقطة يومية من **`AreaStat`** إلى **`RealEstateIndex`** بصف واحد لكل حي:  
   `property_type = "all"` (إجمالي الحي كما تعيده البورصة، وليس تفصيلاً لكل نوع عقار في الصفقة).

3. **`run_fetch_and_store_srem_indices()`** (`market/tasks.py`)  
   ينفّذ (1) ثم (2). زر «تحديث الآن» في لوحة البورصة يستدعي هذه المهمة.

## الإعدادات (`core/settings.py` أو متغيرات البيئة)
- **`SREM_JEDDAH_CITY_SERIAL`** (افتراضي `37528`) — رمز مدينة جدة في API. إذا كانت النتائج فارغة، جرّب `0` أو رمز مدينة أخرى حسب وثائق وزارة العدل/الشبكة.
- **`SREM_DEFAULT_CITY_NAME`** — اسم المدينة عند غياب `CityName` في الاستجابة.
- **`SREM_DASHBOARD_CITIES`** — قائمة مدن لوحة «مؤشرات البورصة» في الأدمن (افتراضي `جدة` فقط). مثال: `جدة,الرياض` بعد أن تُزامن بيانات الرياض من API وتُحفظ بنفس اسم المدينة في `RealEstateIndex`.
- **`SREM_USE_TRENDING_DISTRICTS`** (افتراضي `True`) — استخدام `GetTrendingDistricts` بدل الاعتماد على `GetAreaInfo` عندما يعيد الأخير فقط «جميع المناطق» بشرائح ساعية.
- **`SREM_ENABLED`** (افتراضي `True`) — عند `False` تُعطّل مزامنة المهمة ولوحة الأدمن لبورصة العدل.
- لوحة الأدمن تعرض فقط **`period=day`** لأن المسار الحالي لا يُنشئ صفوفاً أسبوعية/شهرية/سنوية؛ اختيار فترات أخرى كان يُظهر جداً فارغة.

## الصيانة
- حذف الملفات التجريبية القديمة: `scraper.py`، `pricing_benchmarks.py`، `district_area_stat_service.py`.
- للتحقق اليدوي: [srem.moj.gov.sa](https://srem.moj.gov.sa).

## ملاحظات
- API قد يغيّر الحقول أو يتطلب رؤوساً إضافية؛ راقب سجلات الخادم عند `IsSuccess=False`.
- تفصيل **أرض/شقة/فيلا** لكل حي يتطلب واجهات API أخرى إن وُجدت في المنصة؛ حالياً يُعرض **الإجمالي الرسمي للحي** فقط.
- استجابة `GetAreaInfo` لبعض المدن تعيد عدة صفوف باسم **«جميع المناطق»** (شرائح زمنية ساعية) دون تفصيل أحياء. الكود يجمع تلك الشرائح **ضمن نفس اليوم التقويمي** (مجموع مساحة وقيمة وصفقات) ويخزّن لقطة يومية واحدة — أرقام من المصدر وليست وهمية.
